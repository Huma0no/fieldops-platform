# Inventory & Restock

**Version:** 1.0
**Date:** 2026-07-30
**Status:** Closed design

## Purpose

Tracking what each technician has on hand, and reconciling what The Company needs to resupply.

## Inventory

- Per-item table, per technician, with an adjustment control.
- Low or negative stock triggers a non-blocking alert — visible, doesn't stop any workflow.
- Refrigerant tracked by type, with a running total per technician.

## Restock

- Restock report is generated by address — showing what was consumed there.
- On return of supplies, the actual received quantity is logged per item (may differ from what was ordered/expected).
- Same checked-by-default / uncheck-to-exclude pattern used elsewhere (Reports, Ledger): every item is included by default, exclude individually as needed.
