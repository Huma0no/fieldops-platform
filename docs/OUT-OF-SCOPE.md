# Out of Scope

**Version:** 1.0
**Date:** 2026-07-30
**Status:** Current

## Purpose

Features deliberately not built for the current version — so they don't get silently re-proposed without knowing they were already considered and cut.

## FieldOps

- **Troubleshooting Engine** — contextual, symptom-based diagnostic tool.
- **In-field manuals** — service manual viewer beyond the per-component LV/Blower links already in Workspace.
- **Voice-to-report** — dictating a completion report instead of using the structured Workspace flow.
- **General/job-less LV and Blower modes** — LV and Blower Data are purely contextual, scoped to the active job's registered equipment only.
- **IA Tech Support** — placeholder exists in earlier layout iterations, not active.
